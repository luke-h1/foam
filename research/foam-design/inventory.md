# Foam screen inventory

Generated 2026-09-11 from a read-only walk of `src/app`, `src/screens`, `src/components` and `src/store/overlays`. Routes live under `src/app`. Most route files are thin and render a component from `src/screens` or `src/components`; the "Primary component file(s)" column names the real UI file.

How to read the columns:

- Presentation comes from the nearest `_layout.tsx` or from `src/components/RootLayout/RootLayoutNav.tsx`. All root-stack groups (`tabs`, `streams`, `chat`, `auth`, `preferences`, `other`) are registered with `headerShown: false` at the root and then set their own headers in their group layout.
- "tab root" means a screen registered with `nativeStackTabRootScreenOptions` (`src/utils/navigation/nativeStackOptions.ts`): iOS large title that collapses on scroll, transparent header. "push" means `nativeStackScreenOptions`: compact title, transparent header on iOS, opaque dark header on Android.
- States: L = loading, E = empty, X = error, T = long-content (numberOfLines / virtualised list). A missing letter means the state is not implemented in that file.
- Colour literal count = quoted `#hex` strings plus `rgba(`/`rgb(` occurrences in the named component files, excluding `src/styles`. Counted with grep, so `boxShadow` strings that hold an `rgba(` are included. Palette references like `Color.zinc[900]` are not literals but bypass the semantic tokens; they are called out in Notes.
